# 测试记录

日期：2026-10-10。通过本地 HTTP 预览，在 Codex 内置浏览器进行实际交互检查。

## 计划检查

- 直接打开 `index.html` 与本地预览均能加载，无外部依赖。
- 可以从开始页完成六个事件，查看幕后证据并进入家务接力。
- 单选或多选判断、返回与重置符合页面提示，没有空状态卡死。
- 接力步骤可以表达察觉、计划、执行、收尾与一项小约定。
- 电脑与手机宽度下，内容可读、按钮可操作、没有主要内容被遮挡。
- 键盘可以到达核心按钮和输入；标签、焦点和非颜色信息清楚。
- 数据含三个性别中立成员、六个时间节点、十二张现场/幕后卡与完整证据。
- 页面明确说明虚构案例；未把选择结果称作真实脑内统计或成员排名。
- 无账号、后台、AI 接口与持久化；刷新后互动记录清空。

## 实际结果

- JavaScript 语法检查通过；页面所引用的固定元素均存在。
- 示例数据检查通过：3 个故事角色、6 个时间节点、12 张现场 / 幕后卡、24 条步骤线索。
- 五人小队可进入现场；空判断会提示，无法直接跳过线索解锁流程。
- 多选有效，“不确定”与具体角色互斥；不同玩家的猜测独立保存。
- 六个节点可以依次揭示、标记感受并进入故事揭晓；统计为剧情中 A 涉及 6 / 6 个事件，B / C 的执行劳动另有文字呈现。
- 第一事件中两位玩家的不同判断均正确显示在观察表；未记录玩家显示“未记录”，没有排名。
- 自定义任务可加入接力；用户输入中的 `<一起>` 按普通文字显示。
- 未分配的接力步骤会提示；完成四步分配、约定内容和开始时间后，三道锁全部打开。
- 不同任务分别保留自己的约定；切换新任务不会继承旧任务约定，切回可恢复。
- 键盘空格选择后焦点保留；侦探页签支持左右箭头、Home、End。
- 1280px 下完成整段体验；390px、320px 下检查调查页及首页，无页面水平溢出。观察表使用自己的横向滚动区域。
- 刷新后回到首页，玩家与互动记录清空；“重新开始”同样清空本次记录。
- 检查时浏览器无脚本错误。

## 测试后修改

1. 翻卡时同步保存当前玩家非空猜测，避免已有人记录后遗漏其他玩家选择。
2. 接力约定按任务隔离保存。
3. 角色选择后恢复键盘焦点，补齐页签键盘操作与关联标签。
4. 统一明亮主题的辅助文字、标签、幕后步骤和手机排版。

## 验证范围

本轮实际测试使用本地 HTTP；离线文件采用普通脚本和相对资源路径，未通过自动化浏览器打开 file 协议。未进行 Safari / Firefox 实测或真实家庭试用。页面的约 2 分钟 / 5–10 分钟是设计目标，仍需真实参与者试玩计时。
