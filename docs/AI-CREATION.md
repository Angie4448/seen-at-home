# AI 辅助创作记录

日期：2026 年 10 月 10 日。

## 人类提出的设定

用户希望为双职工家庭制作可互动网页，让容易被忽略的家庭劳动被看见和讨论，并作为课程作业与可上传 GitHub 的开源项目。用户要求先通过可视化 HTML 确认需求，并提供 Markdown 反馈导出。

需求阶段提出五个互动想法，用户进一步提出“谁在想下一步？”早晨回放侦探，要求结合家务接力地图与密室主题。最后采用 07:00–07:40 的虚构早晨、同屏参与、中文、明亮轻松的视觉、纯静态实现、MIT 许可证与完整本地交付。正式体验不提供 Markdown 导出。

## AI 参与的工作

AI 把讨论内容整理为体验流程、角色、六个调查节点与幕后证据，编写 HTML、CSS、JavaScript 和项目文档。研究连接通过联网查阅 Haicault 1984 年原论文核实，用来解释持续协调的隐形劳动；没有把虚构案例中的安排分布写成研究结论。

Vibe Coding 的迭代过程是：说明目标与限制 → 整理需求并确认 → 生成互动网页 → 实际检查关键流程与排版 → 根据发现修订。具体测试完成情况以 [TESTING.md](TESTING.md) 为准；没有开展真实家庭访谈或用户研究。

## 可复用提示词

> 为 3–5 人同屏讨论制作简体中文静态网页。主题是看见家庭隐形劳动。用家庭侦探回放 07:00–07:40 的六个虚构事件，先判断谁在预想下一步，再揭示察觉、计划、执行、收尾的证据。使用性别中立角色，孩子可读，明亮轻松，可键盘操作，兼容手机。故事中成人 A 持续协调，其他成员也参与执行。结尾让大家完成一次完整家务接力。不要排名，不要把案例称作真实脑内测量。无注册、后端、AI 接口、持久化或体验 Markdown 导出。交付易读源代码、中文 README、MIT 许可证和 GitHub Pages 发布步骤。

> 检查开始体验、六个事件、选择反馈、幕后证据、回放结束和家务接力流程。检查窄屏排版、键盘焦点和表单标签。只记录实际完成的测试，对失败处修订后复查。

## 内容边界

这是教学与讨论原型。故事创作不等于研究发现；页面选择不等于心理测量；尚未进行的测试不记作已通过。贡献者可替换案例与交互，并保留这些边界说明。
