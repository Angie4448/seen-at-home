# 看见家庭隐形劳动 · 谁在想下一步？

一个简体中文互动网页：跟随“家庭侦探”回放 07:00–07:40 的虚构早晨，发现看得见的家务背后的察觉、计划与跟进，再尝试一次完整的家务接力。

[在线体验](https://angie4448.github.io/seen-at-home/) · [GitHub 源码](https://github.com/Angie4448/seen-at-home) · [MIT 许可证](LICENSE)

适合课程作业、课堂展示，以及 3–5 位家庭成员同屏讨论。完整体验约 5–10 分钟，其中调查回放约 2 分钟，按自己的节奏推进。故事包含两位成人和一位孩子，角色不指定性别。孩子可以一起读线索、表达观察；承担任务时仍应按年龄和能力安排。

## 运行

这是纯静态项目。直接用现代浏览器打开 `index.html` 即可离线体验。无需注册、安装依赖、后台服务或 AI 接口。

若已安装 Node.js，也可在项目文件夹打开终端，运行：

```text
node preview-server.cjs
```

打开终端提示的本地地址。按 `Ctrl+C` 停止预览。

## 体验内容

- 六个早晨节点：早餐、红领巾、学校文件、下雨、补给、出门。
- 每个节点含一张现场卡和一张幕后卡，共 12 张内容卡。
- 根据现场判断谁在预想下一步，再查看故事中设置的准备、执行和跟进证据。
- 看见“动手完成”与“察觉、计划、跟进”之间的区别，比较自己的观察与案例线索。
- 用家务接力把一件事拆成察觉、计划、执行、收尾，写下适合自己家庭的小约定。

本项目不提供体验结果的 Markdown 导出。制作前使用的需求确认网页是单独的材料，其反馈导出功能不属于此正式原型。

## 从五个想法到一个原型

| 想法 | 核心互动 | 帮助看见什么 |
| --- | --- | --- |
| 家庭劳动冰山 | 点击家务卡，展开水面下的步骤 | 完成一件事之前、之后的隐形工作 |
| 家里的 24 小时 | 沿时间轴查看家务和中断 | 工作与家庭安排怎样交织 |
| 被记住的小事 | 点亮小事星图，补充自己的卡片 | 容易被当作理所当然的劳动 |
| 换位的一天 | 通过分支选择应对临时变化 | 提前准备和协调的作用 |
| 家务接力地图 | 安排察觉、计划、执行、收尾 | 完整交接怎样减少反复提醒 |

最后采用用户提出的“谁在想下一步？”早晨侦探主题，并结合家庭劳动冰山的幕后揭示与家务接力地图的完整交接。轻量密室主题以寻找线索、解开家庭安排为体验线索，方便短时间展示。

## 案例与研究说明

角色、现场、证物和安排分布全部是创作的虚构案例。默认故事中，成人 A 涉及六个节点的预先安排和跟进；成人 B 与孩子 C 参与执行。它用于引发讨论，不代表所有家庭，也不测量真实成员的脑内活动、贡献、心理负荷或公平程度。选择结果不是对任何人的诊断或排名。

研究启发来自 Monique Haicault 的 [La gestion ordinaire de la vie en deux（1984）](https://www.persee.fr/doc/sotra_0038-0296_1984_num_26_3_2072)，发表于 *Sociologie du travail*，26(3)，268–277，DOI：10.3406/sotra.1984.2072。文章讨论家庭与职业生活交织，以及协调时间与空间所产生的 **charge mentale**。这启发我们呈现“动手之外，谁在持续察觉、预想和协调”。原研究不能证明“所有家庭始终只有一个人在想下一步”，也不能替这个游戏提供真实脑内人数统计。

## 隐私

项目没有账号、后端、统计追踪或 AI API 调用。互动记录只存在当前页面的内存中；刷新或关闭页面后不保留。公开源码只包含虚构示例，不包含真实家庭记录、账号凭据或 API 密钥。多人共用屏幕时，请自行决定愿意分享的内容。

## 上传 GitHub 与发布 GitHub Pages

1. 登录 GitHub，创建名为 `seen-at-home` 的公开仓库。
2. 在仓库选择 **Add file → Upload files**，把本项目中的文件与文件夹上传到仓库根目录。确认 `index.html` 在根目录，而不是又嵌套一层 `seen-at-home` 文件夹。
3. 提交文件。GitHub 会保留 `LICENSE` 中的 MIT 许可证。
4. 进入 **Settings → Pages**，在 **Build and deployment** 的 **Source** 选择 **Deploy from a branch**。
5. 选择实际上传文件的分支（通常是 `main`）和 **/(root)**，点击 **Save**。
6. 部署完成后，打开 Pages 提供的网址，检查调查、幕后揭示和家务接力能否完成。

## 文件与二次创作

`index.html`、样式文件和交互脚本构成网页；`data.js` 提供角色与六个案例节点；`preview-server.cjs` 用于可选的本地预览。修改 `data.js` 可替换故事与证据，但请继续明确区分虚构案例和真实研究结论。
